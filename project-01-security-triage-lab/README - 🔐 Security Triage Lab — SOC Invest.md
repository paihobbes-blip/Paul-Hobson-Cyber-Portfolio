# 🔐 Security Triage Lab — SOC Investigation Simulations

> Note: This case study uses simulated but realistically structured log data for demonstration purposes only. No real customer or production data is included.

## 📌 Overview

This project demonstrates my approach to **security alert triage and investigation**, simulating real-world SOC (Security Operations Center) workflows.

The goal is to show:
- How I analyse alerts  
- How I form and test hypotheses  
- How I assess risk  
- How I make decisions under uncertainty  
- How I document findings clearly  

---

## 🎯 Purpose

Rather than focusing purely on tools, this lab focuses on:

> 🧠 **Analytical thinking, structured investigation, and decision-making**

Each case simulates a realistic security scenario and walks through:
- Alert context  
- Evidence analysis  
- Hypothesis generation  
- Risk assessment  
- Recommended actions  

---

## 🧩 Case Studies

### Case 01 — Impossible Travel Login
A user account appears to log in from two geographically distant locations within an impossible timeframe.

Focus areas:
- Identity compromise detection  
- Log interpretation  
- Risk evaluation  
- Escalation decisions

## 🤖 AI Usage & Validation

AI tools were used selectively to assist with:
- Structuring raw data  
- Summarising log patterns  

All outputs were:
- Reviewed manually  
- Validated against context  
- Adjusted based on security reasoning  

> ⚠️ AI was treated as an assistant — not a decision-maker.
